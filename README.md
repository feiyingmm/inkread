# 墨阅 Inkread

> 让每一篇 Markdown 静静展开,如书页般被阅读。

墨阅是一款跨平台的 Markdown 文档管理与阅读应用。它相信文档的归宿是被阅读,而非被编辑——打开即是排版精美的阅读视图;需要落笔时,一键切换至 Typora 式所见即所得编辑。文档库经 git 同步,Windows 与 Android 一套代码。

文库既可以是 git 仓库(带同步),也可以是本地任意一个文件夹(比如攒下来的电子书目录)。

核心场景:随时随地阅读 git 仓库中由 Claude 等工具生成的 Markdown 文档库。

## 功能全景(v0.4.x)

### 阅读

- 完整渲染管线:表格、代码高亮(一键复制)、**Mermaid 图表**(点击放大)、**KaTeX 公式**、相对链接应用内跳转(含锚点)、图片预览放大
- **文内目录**:层级树(缩进 + 层级线 + 逐级递弱字重),滚动联动高亮且当前项自动滚进视野;每节可单独折叠,顶部一键折叠 / 展开全部(标题栏吸顶);折叠着也会标出"当前正读在哪一节"
- **长表格浮动表头**:高过一屏的表格滚过表头后,另画一份钉在内容区顶部并跟着横滚同步 —— 不改变任何滚动行为(不做嵌套滚动),几十行的接口参数表也知道哪列是哪列
- **超长代码块自动折起**(>26 行,底部渐隐 + 「展开全部 N 行」);长行代码块带「折行」开关
- **标题悬停出「#」**:一键复制指向本节的 Markdown 链接(`[标题](仓库内路径#锚点)`),回 INDEX.md 挂链接直接可用
- **元信息卡**:识别文档头部 `> - **产品**: …` 式元信息块,渲染为结构化信息卡;放不下的长字段自动独占整行,仍放不下才单行截断(悬停看全文),不会互相压字
- **JSON 一键格式化**:```json 代码块与 `.json` 文件的代码头多一个「格式化 / 原文」按钮,压成一行的接口报文点一下展开缩进;自研格式化器不经 `JSON.parse`,19 位雪花 ID 不会被改精度
- 阅读进度条(按正文实际结束处计算,底部留白不影响)+ 回到顶部;标题折叠(h2/h3,TOC/搜索跳转自动展开)
- 正文底部留一屏三成空白(Typora / 语雀同款):末尾标题也能被大纲滚到顶部
- 书卷版心 / 宽页展开两档宽度;左右侧栏拖拽调宽;全部记忆
- 滚动位置瞬时恢复;冷启动自动回到上次阅读的文档
- 源码模式(`Ctrl+/`)查看原始 Markdown
- 纸色主题:默认 / 羊皮 / 豆绿(浅色模式);品牌主题墨青 / 紫罗兰 × 深浅色
- 中文衬线字体(霞鹜文楷屏幕阅读版)按需加载

### 检索

- `Ctrl+P` 快速打开:文件名模糊匹配;空输入显示最近阅读
- `Ctrl+Shift+F` 全文搜索:结果按文件分组带上下文摘要;跳转后命中导航条(计数 + 上一处/下一处,当前命中高亮)
- 面包屑目录段可点击,在文库树中定位展开

### 编辑(桌面)

- Typora 式纯所见即所得(无富文本工具栏),`Ctrl+E` 切换
- **Markdown 快捷键齐活**:`Ctrl+B` 加粗 / `Ctrl+I` 斜体 / `Ctrl+K` 链接 / `Ctrl+D` 删除线 / `Ctrl+G` 行内代码 / `Ctrl+U` 代码块 / `Ctrl+;` 引用 / `Ctrl+L`·`Ctrl+O`·`Ctrl+J` 三种列表 / `Ctrl+M` 表格 / `Ctrl+Shift+H` 分割线(光标在编辑器内时 `Ctrl+B` 归加粗,不再收文库栏)
- **`Ctrl+F` 查找 / `Ctrl+H` 替换**:全部命中高亮 + 当前命中橙色、计数与上下处导航、区分大小写开关、替换本处 / 全部替换(`Ctrl+Z` 可撤回);选中文字按 `Ctrl+F` 自动带入查找框
- 输入 `/` 唤起块插入菜单:代码块(json/sql/java 等 11 种语言)、表格、任务列表、引用、分割线、公式块
- 底部状态条实时字数 / 行数,选中文字时改报选中字数
- **大纲在编辑视图同样可用**:边写边更新(标题变了才刷,不冲掉折叠状态),点击滚到对应标题并闪一下,滚动时当前标题联动高亮
- **`Ctrl+Alt+J` 格式化文中所有 ```json 代码块**(顶栏也有按钮):不合法的原样跳过并报数,`Ctrl+Z` 可整体撤回
- 正文底部留一屏三成空白(Typora / 语雀同款):末尾标题也能被大纲滚到顶部,文末打字不贴窗口底边
- 顶栏保存按钮(未保存高亮)+ `Ctrl+S`;设置可开自动保存(停笔 2 秒)
- 粘贴截图自动保存到文档旁 `assets/` 并插入相对链接

### 文件管理

- 文件树右键(桌面)/长按(手机)条目菜单:新建文档、新建文件夹(目录内)、**文件信息**(类型 / 大小 / 行数字数 / 修改与创建时间 / git 本地状态 / 绝对路径;文件夹为子项合计)、**以新窗口打开**(桌面)、**打开所在目录**(桌面)、**复制绝对路径**、重命名、删除
- 树列表空白处右键/长按:在文库根目录新建
- 排序:目录在前;同类按**中文拼音序**,数字按数值大小(`文档2` 在 `文档10` 前)
- 新建文件夹自动放置 `.gitkeep` 占位(空目录进不了 git,保证多端同步不丢目录)
- 重命名当前打开的文档自动跟随新路径;删除有确认提示

### Git 同步

- 文库 = git 仓库:添加本地已有仓库(桌面系统目录对话框;Android 应用内目录浏览器,git 仓库标徽标点选即添加)或克隆远程仓库(HTTPS + 访问令牌,按域名保存)
- 启动自动拉取(可关);底部状态条显示分支 / 领先落后 / 未提交变更数
- **本地变更面板**:点状态条查看全部改动明细(改/增/新/删/移);**点文件看改动对比**(与最近提交逐行对比:两列行号、`+`/`−` 标记、块间标出跳过了多少未改动行;新增文件全绿、删除文件全红、二进制只报大小;桌面左列表右对比,手机点进二级页),对比头部可直接「打开」文件或「撤销修改」(恢复最近提交版本;未跟踪文件=删除),面板内一键提交推送(提交信息自动生成)
- 拉取按钮右键(桌面)/长按(手机):普通拉取 / 放弃本地修改与远端一致
- **同步铁律:永不覆盖远程、不代做合并**——无冲突时标准 git 自动合并;真冲突弹窗提示用外部 git 工具处理,软件内仅提供「放弃本地修改,与远端一致」兜底(未跟踪文件保留)
- 文件树与全文搜索尊重 `.gitignore`

### 平台

- **Windows**:NSIS 安装包;`.md` 文件关联(双击 / 右键打开方式),单文件以所在目录建临时文库打开(之后把同一目录正式添加为文库会直接切过去并转正,不再提示"已添加");单实例(一个进程)+ 多窗口(文件树右键「以新窗口打开」、再次双击 md 另开窗口);`Ctrl+滚轮` / `Ctrl+加减` 缩放整页;弹窗关闭按钮在右上角;**关闭按钮行为可选**(设置 → 窗口):默认直接退出,也可改为**收进系统托盘**——托盘图标只在这一档才出现,左键还原窗口、右键菜单退出
- **Android**:纯阅读(无编辑入口);**所有界面为整屏页**——顶部标题栏 + 左上角返回(文库、设置两级、克隆、添加本地仓库、新建/重命名、本地变更、目录、搜索);**系统返回键/返回手势逐层退回**(先关当前层 → 再退阅读历史 → 都没有才收到后台);**软键盘自动避让**(弹层整体抬到键盘上沿);右下浮动球呼出目录、双指捏合调字号、点正文空白沉浸阅读(顶栏/状态条隐现,Markdown / 电子书 / PDF 三种阅读视图都可以);**「所有文件访问」权限三处入口**:首次启动引导、添加本地仓库时拦截、设置 → 存储权限手动开;克隆远程仓库离线阅读

### 查找

`Ctrl+F` 在**每种阅读视图**里都能用,只是各自的搜法不同:

- **Markdown / HTML**:当前文档的 DOM 里找,逐处跳转
- **电子书**:默认只搜当前窗口那几章(即时);点「全书」逐章扫一遍,结果按"哪些章有命中"给,上下键跨章跳(实测 1839 章的 EPUB 扫完 1.5 秒、2004 章的 MOBI 0.3 秒)
- **PDF**:逐页取文本层内容搜索,结果按页聚合,跳到页上后在该页文本层里重新精确定位

高亮走 CSS Custom Highlight API 而不是往正文里插 `<mark>` —— 不碰 DOM 结构,所以折叠状态、原样渲染的 HTML 卡片布局都不会被查找带坏。

### 导出

- 自包含 HTML(样式内联、图片转 base64,单文件可分享)
- **PNG 长图**:按 A4 纸宽(794px)排版 2 倍图,与打印件同一版式、与窗口大小无关;等字体就位后再截、按当前纸色垫底。<br>单张上限桌面 30000px、手机 8000px(Chromium 的 canvas 单边 65535px、面积约 268M px²,越界不报错而是静默给空白图,移动端限制小得多)。超长文档**分段截取**并按 `名字-1.png`、`名字-2.png` 落盘 —— 一般文档一张就够,十几万字的长文才会分段
- 打印 / 另存 PDF

markdown 与 html 文档都可用。

## 支持打开的文件格式

| 类别 | 扩展名 | 能力 |
|------|--------|------|
| Markdown | md、markdown | 完整渲染;桌面可编辑 |
| 电子书 | epub、mobi、prc | **下滑连着读**:滚到底自动接下一章(DOM 里只留相邻 3 章,滑动窗口两端进出并补偿滚动位置,所以上千章的书也不卡);**开篇是不满一屏的版权页 / 短章时会自动先接够**,不会出现"页脚写着继续下滑却划不动";章节很短的书(语录 / 诗集)前后翻都顺、不会越翻越往后;调字号 / 转屏后内容不卡住;重开书回到上次的精确位置;目录跳章、记住读到第几章第几行;正文套用墨阅自己的排版旋钮(字体 / 行距 / 字距 / 纸色),书自带的 CSS 一律剥掉。**按需解压**——只解当前章,不把整包摊进内存(实测 1839 章 / 12MB 的 EPUB 冷启动 0.75 秒、2469 章 / 41MB 的 MOBI 0.84 秒)。EPUB 认 NCX 与 nav 两代目录;MOBI 支持 MOBI6 + PalmDOC 压缩,章名从章节分隔符后的正文就手提取(覆盖约 94%),Calibre 出的书(目录用 `<a filepos>` 排在书尾)目录与章节一一对应不重复;kindlegen 用来做缩进的 `<blockquote>` 一律拆平、书内指定的字色 / 字体一律剥掉,段落不会莫名带底色。不支持 DRM 加密、KF8 / AZW3(会提示用 Calibre 转 EPUB)、固定版式(漫画类) |
| PDF | pdf | 连续滚动阅读 + PDF 自带书签当大纲 + 缩放/适宽 + 记住读到第几页。**只渲染视口附近几页**,离场即释放位图(实测 206 页的书常驻 3 个 canvas、堆内存 14MB)。**带文本层**,所以能选中、复制、查找。用 pdf.js 的 legacy 构建(自带 polyfill),老版 Android WebView 上也能开;**解码器与 CJK 字体映射表随包携带**(JBIG2 / JPEG2000 / ICC 解码器 + GBK / UniGB 等 cMap):整页黑白扫描图的**扫描版 PDF 也能正常显示**,不会只出封面、后面全白;没嵌字体、只写了 GBK 编码的 PDF(常见于 OCR 扫描件与政务通知)**文字照样能选中、复制、查找**。PDF 是固定版式,排版旋钮对它无效 |
| 图片 | png、jpg、jpeg、gif、webp、svg、ico、bmp | 预览 + 点击放大 |
| HTML | html、htm | **渲染着读**,按文档自己有没有样式分两种:<br>· **自带 `<style>` / 行内样式 → 原样渲染**,与浏览器打开一致(卡片、网格、配色本身就是内容)。它的 CSS 会被套上作用域前缀再注入,不会泄到应用界面;`body{}` 规则改写到容器自身,`@import` 丢弃。这种模式下排版四旋钮不生效(文档有自己的设计)<br>· **裸 HTML(只有语义标签)→ 套阅读排版**,与 markdown 一个待遇<br>两种模式都会剥掉 script / 事件属性 / `javascript:` 链接,给标题补 id 进大纲,相对图片与仓库内链接照常可用;`Ctrl+/` 看源码,导出 HTML / PNG 长图都支持 |
| 文本 | txt、sql、json、yml、yaml、xml、csv、js、ts、css、sh、py、java、properties、conf、ini、log | 只读代码视图(语法高亮 + 复制;json 可一键格式化)。编码自动识别:带 BOM 的 UTF-8 / UTF-16(如 Windows 的 `desktop.ini`)、UTF-8、GBK/GB18030 都能读 |

## 技术栈

Tauri 2(Windows + Android 一套代码)· Vue 3 + TypeScript + Vite · markdown-it 15 渲染管线 · Vditor 编辑器 · Rust git2(libgit2)

架构要点:前端一切数据操作经 `Backend` 适配层单一契约——开发期由 Vite Node 中间件实现(调本机 git/fs,浏览器即可开发全部真实功能),打包后切换到 Rust 命令,两端行为一致。

## 开发

```bash
npm install        # postinstall 自动拷贝 Vditor 资源与 pdf.js 解码器 wasm / CJK 字体映射表
npm run dev        # http://localhost:5173,本机零 Rust/零 VS Build Tools
npm run typecheck
```

开发期仓库注册在 `dev-server/repos.local.json`(首次启动自动生成)。

## 发版

三处版本号一致(`package.json` / `src-tauri/tauri.conf.json` / `src-tauri/Cargo.toml`)后:

```bash
git tag vX.Y.Z && git push origin main vX.Y.Z
```

GitHub Actions 自动构建 Windows NSIS 安装包与 Android arm64 APK(已签名,可覆盖升级),挂到 Release。
